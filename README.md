# 🌱 Crop Recommendation System

An AI/ML-based web application that recommends a suitable crop based on soil and weather conditions.

## 🚀 Features

- 🌱 Crop recommendation using Machine Learning
- 🤖 Random Forest Classifier
- 📊 Prediction confidence
- 🌾 Basic crop information
- 🇮🇳 English/Hindi interface
- 📱 Responsive design
- 🌐 Flask web application

## 🧠 Machine Learning

The project uses a Random Forest Classifier trained on the Crop Recommendation dataset.

### Input Features

- Nitrogen (N)
- Phosphorus (P)
- Potassium (K)
- Temperature
- Humidity
- pH
- Rainfall

### Output

The model predicts the most suitable crop based on the provided conditions.

## 📊 Dataset

The dataset contains 2,200 records and 8 columns.

Features:
